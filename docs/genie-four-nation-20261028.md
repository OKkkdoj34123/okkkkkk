## 功能变化

1. 副本中的普通灯神按钮使用与相邻按钮相同的普通小按钮样式，原副本功能和灯神扫荡保留。
2. 默认魏2、蜀2、吴2、群4；四项分别可设0–10整数，总和1–10；0跳过该国。固定按魏→蜀→吴→群执行，不把未用次数转配给其他国。
3. 去掉单独“读取并预览”操作和开始前预览门槛。选账号、配置、点开始即可；阵容/宠物/开启条件/共享次数仍在实际发送前读取并验证。执行表显示当前国家、实际站位、宠物和结果。
4. “计数缺失或统计日期早于今天时，允许受限首战”默认开启，可以手动关闭。仅未知计数时允许1次首战；之后必须取得当日1–10有效计数、战报与进度对应，才按剩余额度继续。不把历史次数当今日0次，不再强制首战后计数必须为1。
5. 服务器明确拒绝且回读确认今日已用10次时，记正常额度停止；未知错误码不直接映射为次数不足。未来时钟/畸形字段/无法核验宠物/未决请求仍停止。
6. 四国共用一个账号的10次额度和未决记录；任一请求超时、断线或结果不明立即停止该账号，不换国重发。开启失败即停止时会停止该账号后续所有国家；默认战败继续。开始互斥和停止按钮保留。
7. 基础阵容、主C插入最强英雄位置、最高已核验hp宠物规则保持。开始前检查全部已选择国家英雄；缺失时不花费第一次挑战。没有科技、养成、主线站位变更；没有接入定时任务。

## 使用与限制

在上述 main 版本项目根目录运行一键py的 `--check`，再 `--apply`；安装器打印备份路径及 `--restore` 命令。无需先应用旧版补丁。重启 `pnpm dev` 并刷新页面，选账号→批量日常→副本→普通灯神挑战→配置→开始。
无有效最高血量比较依据的增强宠物仍会停止；主C站位变化不会继承吕布养成，所以其他国家可能仍然战败。
只去掉用户手动预览步骤，没有跳过必要角色读取；不支持深海、自动周计划或科技自动切换。用户自己的浏览器端实服运行还需当地环境确认，不能把本轮Node协议实测当作所有浏览器环境均已验证。

## 采集范围与限制

- 版本字段是源代码基线和补丁标识，不伪称当前部署构建SHA。
- 批次、账号别名/批内编号、会话编号、战场/角色/军团、原有执行记录和每次状态更新。
- 地图标识和动态buildingData、marches、legionInfo中的大本营/建筑归属结构；保留当前角色字段以识别协议差异，不导出所有玩家角色资料。
- 每个收到的战场包记录命令/seq/resp/code和来源（socket或resolved-body）。相同地图用显式标记引用本会话前一地图；角色变化及后续地图变化照常保留。
- 选点前保存完整必要地图字段，并额外解释己方可穿越路径、候选地块和排除原因。解释器只读，业务仍由原nearestTarget决定。
- 行军/攻击的必要参数、请求序号、响应关联、拒绝回包、超时/断线，以及最终结算。时间来自浏览器ISO时间，可由请求/响应时间推算耗时；主连接入口不伪造无法取得的序号。
- JSON脱敏Token、sid、鉴权、URL和二进制内容；保留数字键对象及缺失/null/0/-1差异。极深层或超长字段以显式标记说明截断。
- IndexedDB独立保存，每2秒合并写入，结束立即发起写入。异常关闭可能丢失最后尚未保存的部分；刷新不能恢复尚未落盘内容。存储失败不影响游戏流程，当前内存仍可导出。
- 单批事件最多12MiB或30000条，保留最早事件，不静默滚动覆盖；`droppedEvents`计数与页面警告标记不完整，最终结果摘要仍保留。上限指事件紧凑序列化大小，格式化导出文件可能更大。
- 不自动下载、不上传JSON、不增加游戏请求、不修改选点/行军/攻击/重试/等待/防重放规则，不重加自动周计划盐场。

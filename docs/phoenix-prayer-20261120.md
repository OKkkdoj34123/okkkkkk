### Windows 使用与恢复

在已回退的仓库根目录打开 PowerShell。`git rev-parse HEAD` 可核对本地提交，脚本的 `--check` 逐一核对目标文件内容。

```powershell
git rev-parse HEAD
python .\patch_fengyi_f6797fca.py --check
python .\patch_fengyi_f6797fca.py --apply
```

应用前会备份 15 个目标的原始状态。首次应用会运行项目验证，验证失败会还原本次写入。若 `--check` 列出内容冲突，先用 `git diff -- 文件路径` 检查。预检遇到冲突会在写入前退出。

需要撤销时，可在相同目录运行下方命令。脚本会核对目标和最近的同一补丁备份。应用后另行编辑过的目标会提示人工核对。

```powershell
python .\patch_fengyi_f6797fca.py --rollback
```
